Key words · 핵심 용어

function
함수
A named block of code that does one job. You can use it again and again.
define · def
정의하다
Create a function. def area(length, width):
call
호출하다
Run the function by using its name. area(4, 3)
parameter
매개변수
The name in the brackets when you define the function. length
argument
인수 (인자)
The value you give when you call the function. 4
return
반환하다
Send a value back to where the function was called.
global variable
전역 변수
A variable made in the main program, outside any function. It can be read anywhere.
scope
범위 (스코프)
The part of the program where a variable exists and can be used.
local variable
지역 변수
A variable made inside a function. It only exists inside that function.
indentation
들여쓰기
The 4 spaces that show which lines belong inside the function.
